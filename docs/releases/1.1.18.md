# MK3 MoveBook 1.1.18 — исправление изображений и шрифтов

Восстановлены готовые ресурсы, пропущенные при сборке 1.1.17: шрифты Russo One и Literata, портреты бойцов, фон книги, иллюстрации истории и изображения секретных кодов. Оформление и сами изображения не изменялись.

В Windows-приложении нажмите **«Обновить»**: пакет с исправлением скачивается и устанавливается автоматически. Ручная распаковка ZIP для этого исправления не нужна. Для версий 1.1.16 и 1.1.17 предусмотрены небольшие пакеты, сохраняющие установленные видео.

На **movebook.ru** исправление применяется после публикации сайта. Если страница была открыта, обновите её.

Сборка теперь проверяет все используемые изображения, шрифты и видео, включая динамические ссылки на портреты. Полный Windows ZIP предназначен для первой установки; механизм достижений и правила учёта матчей сохранены.
