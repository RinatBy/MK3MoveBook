# MK3 MoveBook

Автономная русскоязычная интерактивная книга приёмов Ultimate Mortal
Kombat 3. Desktop-приложение открывает локальный интерфейс через Microsoft
Edge WebView2 и не требует запущенной игры.

## Возможности

- 27 бойцов и две версии набора приёмов;
- разделы «Приёмы», «История», «Факты» и «Секреты и коды»;
- обозначения кнопок UMK3 и SEGA;
- поиск по бойцам и приёмам;
- локальные видео демонстраций;
- обновление содержимого книги через GitHub Releases;
- проверка SHA-256 и автоматический возврат к встроенной версии при ошибке.

## Запуск готовой версии

1. Скачайте архив из раздела Releases.
2. Распакуйте его в отдельную папку.
3. Запустите `MK3 MoveBook.exe`.

Подробная диагностика MAME и локальный CSV-отчёт отключены по умолчанию. Для
согласованного исследовательского запуска используйте
`MK3 MoveBook.exe --diagnostics`.

Если WebView2 недоступен, запустите `Web MK3 MBook.exe`. Локальная
веб-версия откроется в браузере, выбранном в Windows по умолчанию.

EXE, DLL-файлы и папка `web` должны оставаться рядом. Для работы требуется
Microsoft Edge WebView2 Runtime, который обычно уже установлен в Windows 10
и Windows 11. Если компонент отсутствует, приложение предложит запустить
официальный Bootstrapper Microsoft из полного архива.

В Windows-приложении нажмите «Обновить»: книга сама скачает пакет, проверит
SHA-256, установит содержимое и перезапустится. Исправление изображений и
оформления 1.1.18 приходит этим способом, без ручной распаковки ZIP.
В обычном браузере кнопка обновления открывает страницу выпуска; опубликованный
movebook.ru обновляется автоматически при публикации релиза.

Встроенное обновление содержимого не заменяет desktop EXE. Полный Windows-пакет
нужен при первой установке или переходе со старого хоста на новые возможности
отслеживания MAME; исправление ресурсов 1.1.18 замены EXE не требует.

Репозиторий хранит исходный код интерфейса и desktop-хоста. Готовый пакет с
необходимыми локальными ресурсами публикуется отдельно в разделе Releases.

## Сборка полного выпуска

Когда изменяется desktop-хост, собирайте новый EXE через `desktop/build.ps1`.
`tools/build-release-from-base.ps1` переиспользует старый desktop-runtime и
подходит только для обновлений содержимого.

Полные архивы можно собрать Python 3.11+:

```powershell
python tools/build-full-release.py --version 1.1.18 --desktop-build desktop/build --media-root ../runtimes/portable-current/web/assets/moves --output-directory ../work/release-output-1.1.18
```

Каталог результата должен быть новым. Скрипт берёт код и изображения из `app/web`,
видео — из явно указанной библиотеки, проверяет ссылки и SHA-256 каждого файла
в готовых архивах. Содержимое runtime-копий не используется как источник кода.

Проверка ресурсов и регрессии комплектации: `python -m unittest discover -s tools/tests -p "test_release_assets.py"`.
