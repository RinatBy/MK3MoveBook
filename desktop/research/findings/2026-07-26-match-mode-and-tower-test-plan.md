# План исследования режима матча и башни

## Цель

Найти устойчивые значения RAM, которые позволяют отличить:

- одиночный бой против компьютера в башне;
- локальный бой двух игроков на одном компьютере;
- сетевой бой через Kaillera;
- завершение выбранной башни от начала до финального экрана.

Пока эти сигналы не подтверждены, локальный прогресс остаётся тестовым и не
использует режим матча как основание для блокировки достижений.

## Контрольные записи режима матча

Каждый сценарий записывается отдельным запуском `MK3 Memory Capture.exe` с одним
и тем же ROM и, по возможности, одной и той же парой бойцов.

1. **CPU / башня** — выбрать башню, провести один полный матч против компьютера,
   дождаться перехода к следующему сопернику и остановить захват через `Ctrl+C`.
2. **Локальные два игрока** — активировать второго игрока, провести один полный
   матч на той же клавиатуре, дождаться итогового экрана и остановить захват.
3. **Kaillera** — провести один полный сетевой матч той же парой бойцов и
   остановить захват после результата.

Читы на здоровье и время разрешены, но здоровье проигравшего должно реально
достичь нуля. Save State между разными режимами не используется.

## Контрольная запись башни

Отдельно записывается одно полное прохождение самой короткой башни:

1. начать захват до экрана выбора башни;
2. выбрать башню и пройти все матчи одним бойцом;
3. дождаться экрана концовки или титров;
4. корректно остановить рекордер через `Ctrl+C`.

Для ускорения разрешены читы. Важно не пропускать переходы между соперниками,
финального босса и первый экран после завершения башни.

## Критерий готовности

Режим можно использовать для защиты достижений только после слепой проверки на
новых записях: найденный сигнал должен стабильно принимать разные значения для
CPU, локального второго игрока и Kaillera и не зависеть от выбранных бойцов,
арены, стороны игрока или читов.
