# Диагностика фактического использования читов MAME 0.129

`MK3 Cheat State Probe.exe` — отдельный исследовательский датчик. Он не является
готовым античитом и не меняет память MAME.

Датчик читает внутренний список `cheat_entry` MAME 0.129 и фиксирует:

- переход постоянно действующего чита из `OFF` в активное состояние;
- уже активный чит на момент подключения;
- сообщение `Activated ...`, которое MAME создаёт при выполнении разовой команды,
  например `Drain all Energy Now! PL2`.

Простое наличие `cheat 1` не считается использованием чита.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build-cheat-probe.ps1
```

Результат: `build\MK3 Cheat State Probe.exe`.

## Контрольный тест

1. Запустить датчик — он будет ждать MAME.
2. Запустить MAME 0.129 и UMK3 Team Edition.
3. Открыть меню читов и последовательно проверить:
   - `Infinite Time`: включить, подождать секунду, выключить;
   - `Infinite Fatality Time`: включить, подождать секунду, выключить;
   - `Infinite Energy PL1`: включить, подождать секунду, выключить;
   - один раз выполнить `Drain all Energy Now! PL2`.
4. Остановить датчик сочетанием `Ctrl+C`.
5. Передать два последних файла из папки `cheat-diagnostics` рядом с EXE.

Для автоматической остановки можно использовать `--seconds N`.

После подтверждения на настоящей сборке MAME тот же механизм можно встроить в
MoveBook: результат защёлкивается до конца CPU-матча и применяется только при
режиме `tower-cpu`. В online-режиме этот сигнал не должен блокировать достижения.
