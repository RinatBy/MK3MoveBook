# Тесты движка достижений

Запуск проверок локального прогресса:

```powershell
node .\achievement-engine.test.mjs
```

Проверяются боевой дебют, сюжетное противостояние, рубежи побед, миграция
старого локального прогресса, защита от повторного события, общие и
персональные добивания, а также ROM-зависимый Antifatality.
