# Синхронизация достижений

Portable-клиент отправляет нормализованные события MAME только после входа
через Discord. Правила достижений выполняются на сервере; JavaScript-интерфейс
лишь отображает полученный серверный снимок.

## API

- `GET /api/v1/achievements/me` возвращает статистику и разблокировки текущего
  пользователя.
- `POST /api/v1/achievements/events` принимает одно событие MAME и возвращает
  обновлённый снимок прогресса.
- Оба endpoint требуют access JWT в заголовке `Authorization: Bearer ...`.
- События дедуплицируются по `(user_id, source, event_key)`, поэтому повторная
  отправка не увеличивает статистику второй раз.

Поддерживаются события `round-ended`, `match-ended` и `finisher`. Сервер хранит
исходный payload события, время и статус проверки `unverified-local`.

## Текущая модель игрока

На этом этапе авторизованный профиль всегда соответствует стороне P1:

- завершённый матч увеличивает `matches_played` независимо от победителя;
- победа, дебют бойца и сюжетное противостояние засчитываются только при победе
  P1;
- Flawless Victory засчитывается только для P1;
- добивания P2 или CPU не засчитываются профилю.

Это временная безопасная модель до появления явной привязки аккаунта к стороне
или игровому месту.

## Поведение клиента

- Без входа каталог достижений доступен только для просмотра; события не
  создаются и прогресс не показывается.
- После входа клиент загружает серверный снимок и начинает захват новых событий.
- Событие, уже видимое в MAME в момент входа, помечается как исходное и не
  отправляется задним числом.
- При временной ошибке сети события остаются в очереди текущего процесса и могут
  быть повторно отправлены кнопкой в интерфейсе.
- Очередь пока не сохраняется между перезапусками Portable-клиента. Закрывать
  приложение с сообщением об остановленной синхронизации не следует.
- Старый локальный прогресс версии `v2` автоматически не импортируется. Новый
  кэш `v3` содержит только последний полученный серверный снимок и не является
  источником истины.

## Локальная проверка

1. Применить миграции и запустить сервер на `127.0.0.1:8010`.
2. Запустить отдельную тестовую Portable-сборку.
3. Войти через Discord и открыть достижения: индикатор должен перейти в
   состояние «Прогресс синхронизирован».
4. Выиграть матч стороной P1: `matches_played` и `victories` должны увеличиться
   только после ответа сервера.
5. Завершить матч победой P2/CPU: должен увеличиться только `matches_played`.
6. Закрыть и снова открыть клиент: серверный прогресс должен восстановиться.
7. Выполнить явный выход: прогресс должен скрыться, а новые события перестать
   учитываться.
